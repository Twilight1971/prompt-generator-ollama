Prompt Generator · Hilfe

Version 3.3 · Ollama Vision · Krea 2

Was ist der Prompt Generator?

Der Prompt Generator analysiert ein hochgeladenes Bild zunächst faktisch mit einem Ollama Vision-Modell. Aus dieser überprüfbaren Analyse entsteht anschließend ein kompakter, natürlicher Prompt speziell für Krea 2. Die Verarbeitung erfolgt auf deinem lokalen oder selbst gewählten Ollama-Server.

Schnellstart

1

Bild hochladen – Ziehe ein Bild (JPG, PNG, WEBP bis 20 MB) in die Drop-Zone oder klicke darauf. Für mehrere Bilder: Batch-Modus aktivieren.

2

Ollama verbinden – Trage die Serveradresse ein, z. B. http://127.0.0.1:11434 oder die IP deines Ollama-Servers im LAN.

3

Modell auswählen – Die App lädt alle auf dem Ollama-Server installierten Modelle. Für Bildanalysen wählst du ein Vision-fähiges Modell.

4

Modus wählen – Mit LoRA 🧬: Gesicht/Haare werden weggelassen (LoRA übernimmt das). Ohne LoRA 🎨: Kompletter Charakter inkl. Gesicht wird beschrieben.

5

Optionen anpassen – Stil, Stimmung, Beleuchtung, Detailgrad, Kamera. Stile: u.a. Instagram Style, TikTok Style. Kameras: iPhone, Webcam, 35mm, 85mm usw.

6

⚡ Generieren – Das Ergebnis erscheint in drei Tabs. Danach: bearbeiten, variieren, exportieren oder in den Verlauf schauen.

Ollama-Verbindung

🦙 Ollama
Kein API-Key erforderlich
Serveradresse und Modell werden automatisch gespeichert.
Beispiel: ollama pull qwen2.5vl:7b

Ausgabe-Tabs & Aktionen

  • 📄 Text Prompt – Fertig formulierter positive_prompt, direkt einfügbar. Klick auf ✏️ Bearbeiten macht ihn editierbar; 💾 Speichern sichert die Änderung.
  • 🔎 Bildanalyse – Zeigt die rein faktische erste Stufe. Hier lässt sich prüfen, ob das Vision-Modell das Bild korrekt verstanden hat.
  • 🗂 Strukturiertes JSON – Enthält den fertigen Krea-2-Prompt zusammen mit Analyse und Fidelity-Hinweisen.
  • ⚙️ ComfyUI / A1111 – Öffnet Export-Modal mit drei Formaten: Automatic1111 (Pos + Neg + Parameter), ComfyUI JSON (CLIPTextEncode-Nodes), FLUX/Fooocus (bereinigter Einzel-Prompt).
  • ✨ Prompt-Variationen – 11 Buttons erscheinen nach der Generierung, darunter iPhone Selfie für einen unperfekten Amateur-Selfie-Look aus Armlänge ohne sichtbares Smartphone. Jede Variation ruft das Modell erneut auf und modifiziert den bestehenden Prompt.

Negative Prompt Editor

Nach der Generierung erscheint unter dem Output-Feld ein editierbares Negative Prompt-Feld. Der automatisch generierte Negative Prompt kann hier direkt angepasst, ergänzt oder gekürzt werden – die Änderungen werden beim Export und beim ComfyUI/A1111-Format berücksichtigt.

Batch-Modus

Oben im Upload-Panel auf Batch schalten. Mehrere Bilder per Drag & Drop oder Klick hinzufügen. Nach Klick auf ⚡ Batch generieren werden alle Bilder nacheinander analysiert. Am Ende wird automatisch eine ZIP-Datei mit .txt und .json für jedes Bild heruntergeladen.

🕘 Prompt-Verlauf

Jeder generierte Prompt (auch Batch und Variationen) wird automatisch im Verlauf gespeichert (max. 20 Einträge, im Browser-localStorage). Der 🕘 Verlauf-Button im Header öffnet das Verlaufs-Modal. Dort kannst du:

  • Prompts nach Datum, Stil, Stimmung, Modell und LoRA-Modus filtern (Tags sichtbar)
  • Einen alten Prompt per Klick wiederherstellen – er erscheint sofort im Output
  • Einzelne Einträge mit ✕ löschen
  • Den gesamten Verlauf löschen

Gespeicherte Ollama-Einstellungen

Serveradresse und ausgewähltes Modell werden lokal gespeichert und beim nächsten Start automatisch wiederhergestellt. Mit ↻ lässt sich die Liste installierter Modelle jederzeit neu laden.

Skin Realism Enhancement

Jeder Prompt enthält automatisch diese Qualitätsanweisung im realism_notes-Feld:

visible pores · skin texture · natural imperfections · subsurface scattering · flyaway hairs · baby hairs catching light · subtle eye moisture · organic texture · ultra-realistic photo-quality finish

Tipps für beste Ergebnisse

  • Bilder mit klarer Beleuchtung und gut sichtbarer Szene liefern die detailliertesten Prompts.
  • Verwende ein Vision-fähiges Ollama-Modell; reine Textmodelle können das hochgeladene Bild nicht analysieren.
  • Nach der Generierung den Prompt im ✏️ Bearbeiten-Modus nachpolieren, dann ComfyUI/A1111 exportieren.
  • Nutze Prompt-Variationen um schnell mehrere Stimmungs-Versionen zu testen, ohne neu hochzuladen.
  • Dark/Light/System-Theme und Sprache werden automatisch gespeichert.
  • Beim ersten Laden eines Modells kann Ollama etwas länger benötigen.

What is the Prompt Generator?

The Prompt Generator first creates a factual analysis of the uploaded image with an Ollama vision model. It then turns that verifiable analysis into a concise natural-language prompt specifically for Krea 2. Processing happens on your local or configured Ollama server.

Quick Start

1

Upload image – Drag a JPG, PNG or WEBP (up to 20 MB) into the drop zone or click to select. For multiple images: enable Batch mode.

2

Connect Ollama – Enter the server URL, e.g. http://127.0.0.1:11434 or your Ollama server's LAN IP.

3

Select a model – The app loads every model installed on the Ollama server. Choose a vision-capable model for image analysis.

4

Choose mode – With LoRA 🧬: face/hair excluded (LoRA handles them). Without LoRA 🎨: full character including face is described.

5

Adjust options – Style, mood, lighting, detail level, camera. Styles include Instagram Style, TikTok Style. Cameras: iPhone, Webcam, 35mm, 85mm etc.

6

⚡ Generate – Results appear in three tabs. Then edit, vary, export or check your history.

Ollama Connection

🦙 Ollama
No API key required
Server URL and model are saved automatically.
Example: ollama pull qwen2.5vl:7b

Output Tabs & Actions

  • 📄 Text Prompt – Ready-to-use positive_prompt. Click ✏️ Edit to make it editable; 💾 Save commits the changes.
  • 🔎 Image Analysis – Shows the strictly factual first stage so you can verify that the vision model understood the image.
  • 🗂 Structured JSON – Contains the finished Krea 2 prompt together with the analysis and fidelity notes.
  • ⚙️ ComfyUI / A1111 – Opens export modal with three formats: Automatic1111 (pos + neg + parameters), ComfyUI JSON (CLIPTextEncode nodes), FLUX/Fooocus (clean single prompt).
  • ✨ Prompt Variations – 11 buttons appear after generation, including iPhone Selfie for an imperfect amateur arm-length selfie with no visible phone. Each calls the model again to modify the existing prompt.

Negative Prompt Editor

After generation, an editable Negative Prompt field appears below the output. The auto-generated negative prompt can be modified, extended or trimmed here – changes are reflected in exports and the ComfyUI/A1111 format modal.

Batch Mode

Switch to Batch in the upload panel header. Add multiple images via drag & drop or click. After clicking ⚡ Run Batch, all images are analysed sequentially. A ZIP file with a .txt and .json for each image is downloaded automatically when done.

🕘 Prompt History

Every generated prompt (including batch and variations) is automatically saved to History (max. 20 entries, stored in browser localStorage). The 🕘 History button in the header opens the history modal where you can:

  • Browse entries with tags showing date, style, mood, model and LoRA mode
  • Restore any old prompt with one click – it appears instantly in the output
  • Delete individual entries with ✕
  • Clear all history

Saved Ollama Settings

The server URL and selected model are stored locally and restored at the next start. Use ↻ to reload the installed model list at any time.

Skin Realism Enhancement

Every prompt automatically includes this quality instruction in the realism_notes field:

visible pores · skin texture · natural imperfections · subsurface scattering · flyaway hairs · baby hairs catching light · subtle eye moisture · organic texture · ultra-realistic photo-quality finish

Tips for Best Results

  • Images with clear lighting and a well-visible scene produce the most detailed prompts.
  • Use an Ollama vision model; text-only models cannot analyze the uploaded image.
  • After generating, polish the prompt in ✏️ Edit mode, then export via ComfyUI/A1111.
  • Use Prompt Variations to quickly test different moods without re-uploading.
  • Dark/Light/System theme and language are saved automatically.
  • Ollama may take longer the first time it loads a model.
